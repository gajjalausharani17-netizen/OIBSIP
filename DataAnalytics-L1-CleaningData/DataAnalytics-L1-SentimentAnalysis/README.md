# Sentiment Analysis – Oasis Infobyte Internship

## Task 4: Sentiment Analysis

### Objective
To analyse customer reviews and classify them as Positive, Negative, or Neutral.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Work Completed
- Created a sample customer review dataset.
- Cleaned text data.
- Classified reviews using a rule-based approach.
- Calculated sentiment counts and percentages.
- Created bar and pie charts.
- Exported results to CSV.

### Files
- Oasis_Sentiment_Analysis.ipynb
- Sentiment_Analysis_Results.csv

### Conclusion
This project demonstrates basic sentiment analysis and helps understand customer opinions from text reviews.
