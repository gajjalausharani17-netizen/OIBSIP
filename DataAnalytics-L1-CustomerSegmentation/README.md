# Oasis Infobyte Internship — Customer Segmentation Analysis

## Project Overview
This project uses K-Means clustering to group mall customers based on their annual income and spending score.

## Objective
To identify different customer segments and understand customer purchasing behaviour.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Analysis Performed
- Dataset loading and inspection
- Missing-value checking
- Feature selection
- Elbow Method
- K-Means clustering
- Customer segment visualization
- Cluster analysis

## Key Findings
Customers were grouped into five clusters based on annual income and spending score. The groups represent different customer spending patterns.

## Business Recommendations
1. Provide loyalty rewards to high-spending customers.
2. Create targeted offers for customers with high income but lower spending.
3. Develop affordable promotions for lower-income customers.
4. Use customer segments for personalized marketing.

## Conclusion
K-Means clustering helps businesses identify customer groups and understand purchasing behaviour. This analysis can support better marketing strategies and customer engagement.
